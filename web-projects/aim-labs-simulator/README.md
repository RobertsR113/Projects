# Aim Labs Simulator

### Created Using:
* Languages: JavaScript, CSS, HTML
* Software: Visual Studio Code
* Libraries: jQuirry

## Goal
To showcase my knowledge and skillset in web-development using JavaScript, CSS and HTML, acquired during my second-year course, JavaScript Fundamentals.

## Features
* A game website to imrpove user reflex skills.
* Scoring system depending how many circles and how quickly they are clicked.
* User can choose difficulty (the higher the difficulty the faster clickable circles appear/dissapear)
* Timer that ends the game after specific time.
* Timer clickable icons to increase the timer time to play the game longer.
* Leaderboard showcasing user name, final score and chosen difficulty.
* User name, score and difficulty are saved in browser local storage.
* Clean and well structured project.
