# Blazor Web Market Simulator

### Created Using:
* Language: C#
* Software: Visual Studio 2026
* Framework: ASP.NET Core

## Goal
To showcase my knowledge and skillset in C#, Blazor acquired during my second-year course, C# Fundamentals.

## Features
* Shop inventory - Add/Remove products or increase their stock/quantity.
* Shop - Purchase multiple products in multiple allowed quanitties.
* Order History - See history of all bought groceries with date and time stamps.
* Clean and well structured project.

1. Download the project `wpf-casino-simulator`
